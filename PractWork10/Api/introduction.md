# Introduction
# Проект API для управления задачами

Этот проект предназначен для создания и управления задачами через API. С помощью данного API пользователи могут создавать, получать, обновлять и удалять задачи.

### Основные функции

- Создание задач
- Получение списка задач
- Получение задач по идентификатору
- Обновление и удаление задач

Данный API использует стандартные HTTP методы (GET, POST, PUT, DELETE) для выполнения операций.
