# Description
# Описание и примеры основных возможностей API

Этот API предназначен для управления задачами. Все операции выполняются по маршруту `/api/Task` и используют стандартные HTTP методы.

## Основные возможности API

### 1. Получение всех задач

- **Метод:GET /api/Task**
- **Описание:** Возвращает список всех задач.
- **Пример запроса:**
```json
  GET /api/Task
[
  {
    "id": 1,
    "name": "сделать круто",
    "description": "крутое задание",
    "endOfTask": "2026-10-01",
    "status": 0
  },
  {
    "id": 2,
    "name": "сделать не круто",
    "description": "не крутое задание",
    "endOfTask": "2025-09-12",
    "status": 1
  }
]
```

### 2. Получение задачи по идентификатору
- **Метод: GET /api/Task/{id}**
- **Описание: Возвращает задачу по её уникальному идентификатору.**
- **Пример запроса:**
```json
GET /api/Task/5
{
  "id": 5,
  "name": "ааааааааааа",
  "description": "я топ",
  "endOfTask": "2025-01-12",
  "status": 1
}
```

### 3. Создание новой задачи
- **Метод: POST /api/Task**
- **Описание: Создаёт новую задачу в системе.**
- **Пример запроса:**
```json
POST /api/Task

{
  "name": "дело123",
  "description": "аписание",
  "endOfTask": "2025-12-31",
  "status": 0
}
```

### 4. Обновление задачи по идентификатору
- **Метод: PUT /api/Task/{id}**
- **Описание: Обновляет данные существующей задачи.**
- **Пример запроса:**
```
PUT /api/Task/3

{
  "name": "новое название",
  "description": "обновлённое описание",
  "endOfTask": "2026-01-01",
  "status": 2
}
```

### 5. Удаление задачи по идентификатору
- **Метод: DELETE /api/Task/{id}**
- **Описание: Удаляет задачу по её уникальному идентификатору.**
- **Пример запроса:**
```
DELETE /api/Task/7
```
